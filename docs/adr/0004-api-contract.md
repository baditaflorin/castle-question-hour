# 0004 — API contract (Mode C)

- Status: accepted
- Date: 2026-05-11

## Decision

REST + JSON for control-plane, WebSocket for signaling. The full schema lives in
[backend/api/openapi.yaml](../../backend/api/openapi.yaml) and the frontend client is generated
from it via `openapi-typescript` so we never hand-write types.

### Endpoints

| Method | Path                                       | Purpose                                              |
|--------|--------------------------------------------|------------------------------------------------------|
| GET    | `/healthz`                                 | liveness                                             |
| GET    | `/readyz`                                  | readiness (LLM + TTS reachable)                      |
| GET    | `/metrics`                                 | Prometheus (blocked at nginx from public)            |
| GET    | `/api/v1/castle/{code}/now`                | current hour's question + bucket id                  |
| GET    | `/api/v1/castle/{code}/history?n=24`       | last N hour buckets (questions only)                 |
| POST   | `/api/v1/castle/{code}/subscribe`          | register a Web Push subscription                     |
| DELETE | `/api/v1/castle/{code}/subscribe`          | unregister                                           |
| POST   | `/api/v1/castle/{code}/summarize`          | steward submits answer text → returns themes + WAV   |
| WS     | `/api/v1/signal/{code}`                    | WebRTC offer/answer/ICE relay                        |
| GET    | `/api/v1/vapid-public-key`                 | the VAPID public key, served at runtime              |

### Castle code

A castle code is `^[a-z0-9]([a-z0-9-]{1,30}[a-z0-9])?$`. Codes are not authenticated — joining
requires *knowing the code*, which is the trust model of a physical castle gathering.

### Errors

Standard JSON: `{"error": {"code": "string", "message": "human readable"}}`. HTTP status mirrors
the error class. Never include stack traces.

## Consequences

- Frontend types are regenerated by `make` and `post-merge` hook (§9).
- Breaking changes bump `/api/v1/` → `/api/v2/`. Backward-compat for at least one minor version.
- Pulling all of this out into a separate `pkg/api` package keeps the contract testable.
